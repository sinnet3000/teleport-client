# Security Policy

## Project status

teleport-client is experimental, reverse-engineered software. It is not an
official Ubiquiti product, and no compatibility, maintenance, response-time, or
support guarantees are provided.

Security fixes are considered on a best-effort basis for the latest version of
the project. Older versions may not receive fixes.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to the maintainer
through GitHub. Do not open a public issue until the report has been reviewed
and any necessary fix has been released.

Include a concise description, affected version or commit, reproduction steps,
and the potential impact. Remove all real credentials and identifying network
information from the report.

## Sensitive information

Do not publish or attach Teleport invite URLs, invite UUIDs, session files,
session tokens, session secrets, private keys, packet captures, or unredacted
debug logs. If any of these are exposed, revoke or replace the affected
credential where possible.

## Authorized use

Use this project only with systems, accounts, networks, and Teleport invites
that you own or are authorized to access. Users are responsible for ensuring
that their use complies with applicable laws, software licenses, service terms,
and Ubiquiti terms.
